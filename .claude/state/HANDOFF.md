## Последние принятые решения

- **PRD для трека сознательно НЕ пишем.** Хендофф Claude Design (27 КБ) — спека выше типового
  PRD: layout по слоям, точные значения, все состояния, модель состояния стора, раздел «что
  делать в кодовой базе». PRD поверх стал бы пересказом, который разъедется с оригиналом.
- **Спека обязана быть в `origin/main` до старта** (PR #419): раннер детачит дерево на
  origin/main, локальных файлов не видит — иначе issues ссылались бы в пустоту.
- **Вывод Claude Design ревьюим рендером и замером, не глазами.** Оба блокера трёх ревизий были
  невидимы на скриншоте: телеметрия поверх танков (полоса 196–301px против танков на 270px) и
  переполнение планшета (`right=926` при `scrollWidth:768`). README хендоффа при этом утверждал
  обратное — верить надо файлу, а не спеке.
- **Геймплейные конфликты называем сами.** Полная парабола-подсказка и точное число ветра
  формально соответствовали брифу, но отменяли пристрелку из GDD. Итог: сегмент ~12% без точки
  падения; ветер — стрелка + грубая сила, точное значение после первого выстрела (`windRevealed`).
- **Фаза 1 — `complexity:high` по риску, не по объёму:** `playerPoints`/`enemyPoints` живут в
  8 файлах (46 вхождений), включая HUD реплея и тест детерминизма, плюс коллекция `scores`.
