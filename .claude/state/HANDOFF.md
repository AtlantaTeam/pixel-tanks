## Последние принятые решения

- **Дисплейный шрифт — DotGothic16** (D7): Pixelify Sans забракован (кириллица неровная), Handjet —
  не игровой. JetBrains Mono (UI/HUD) остаётся.
- **Эмодзи как иконка ЗАПРЕЩЕНЫ**: нет иконки → блокер, требовать у дизайна, НЕ эмодзи-фолбэк. SVG
  icon-set (28 имён) в инвентаре полный; без иконки только `angle`/`power` (∠/⚡) — это HUD игрового трека.
- **Витрина показывает все элементы и состояния СТАТИЧНО** — без interaction-gated демо (клики/фокусы/
  раскрытия), каждое состояние отдельным срезом (консистентность + визрегрессия). Требование в PRD.
- **Игровой экран (Canvas/арена/тач) — отдельный трек**: арена/фон/танки — сменяемый арт (память
  `arena-tanks-are-skinnable-art`), система энфорсит только UI-оболочку.
