## Цепочка #489: инструмента не было, а правило на него опиралось

Телеметрия уезжала на **+126 px за край** при `scrollWidth` = вьюпорту (контент недоступен).
Причина не в вёрстке: правило требовало проверки через Playwright MCP, а **MCP не работал** —
провижн ставил только `chromium`, брендированный `chrome` не ставил никто.

1. Chrome поставлен (151.0.7922.137), MCP работает.
2. **Провижн** (#499) ставит оба канала и **сам пробует запустить браузер**.
3. **Правило** (#498): проверка — скриптом с локальным `playwright`, плюс вывод замера
   обязан быть в комментарии закрытия (транскрипты сессий не хранятся, #346).

**У кодер-сессий MCP нет вообще** — серверы прописаны только для `/root/medods-bridge`.
Обязательные шаги не должны опираться на MCP, только на то, что лежит в репозитории.
