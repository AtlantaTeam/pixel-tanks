# Rules

Файлы правил подключаются в контекст ТОЛЬКО когда агент работает с файлами, совпадающими с паттерном в frontmatter (`globs`). Это экономит контекст: правило про Payload не грузится при вёрстке.

Принцип: **чем специфичнее правило — тем точнее механизм подключения**.

- Нужно всегда → корневой CLAUDE.md
- Нужно для пакета/модуля → вложенный CLAUDE.md в его директории
- Нужно для типа файлов → сюда, в rules с `globs`
- Нужно разово → явный контекст `@файл` в промпте

Итерируй по принципу «одна повторяющаяся ошибка агента — одно правило».

## Актуальные правила

| Файл                        | Globs (когда грузится)                                    | О чём                                                 |
| --------------------------- | --------------------------------------------------------- | ----------------------------------------------------- |
| `canvas.md`                 | `src/features/game-engine/**`, `src/shared/lib/canvas/**` | Игровой цикл, детерминированная физика, рендер        |
| `payload.md`                | `src/payload/**`, `src/app/(payload)/**`                  | Payload CMS: Local API, access, hooks, типы           |
| `tests.md`                  | `**/*.{spec,test}.{ts,tsx,js,jsx}`                        | Поведение вместо реализации, негативные сценарии      |
| `design-system-showcase.md` | `src/shared/ui/**`, `src/views/design-system/**`          | Витрина `/design-system` = Storybook всех компонентов |
| `ralph-typescript.md`       | `.claude/ralph/**`                                        | Код раннера — TS по умолчанию; `.js` только для entry |

Добавил правило — впиши строку сюда, чтобы папка оставалась самодокументируемой.
