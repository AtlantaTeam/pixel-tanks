# PRD: Верстка дизайн-системы (кодификация инвентаря в код)

**Дата**: 2026-07-24
**Статус**: Draft

## Цель

Превратить финализированный дизайн-инвентарь Claude Design
(`docs/design-system-theming/design-inventory.dc.html`, DotGothic16) в рабочий код: полный набор
токенов, типографики, иконок, компонентов, состояний, попапов и экранов на реальном стеке
(React 19 + Tailwind 4 + FSD), и вывести всё на витрину `/design-system` как **единый статичный
консистентный каталог**. Чтобы весь UI игры собирался из готовых выверенных элементов, а не
хардкодился, и любой дрейф ловился визрегрессией.

## Пользовательские сценарии

- Разработчик/агент берёт готовый `<Button>` / `<Dialog>` / `<Toast>` / `<Icon>` из `shared/ui` →
  собирает экран без хардкода цветов/иконок.
- Человек открывает `/design-system` → видит **все элементы и все их состояния разом, статично**
  (без кликов и раскрытий) → судит консистентность вида целиком.
- Визуальная регрессия снимает `/design-system` → ловит любое отклонение от инвентаря.

## В скоупе

- **Токены/типографика**: DotGothic16 self-host (display) + JetBrains Mono (UI/HUD); сверить
  палитру/эффекты/радиусы/шкалу с инвентарём, добить недостающее.
- **Иконки**: извлечь SVG icon-set (28 имён) из инвентаря → `shared/ui/icon` (`<Icon name>`,
  `currentColor`, тема-aware); подключить `<Icon>` ВЕЗДЕ, где в инвентаре стоят эмодзи/глифы
  (🔥☠★✓✕◈✸⇩▶❚⏭⏮🙈👁↻⚠ — все покрыты набором). **Жёсткое правило: эмодзи/юникод-пиктограммы как
  иконки ЗАПРЕЩЕНЫ.** Нужной иконки нет в наборе → это **блокер**: требовать её у дизайна
  (Claude Design), НИКОГДА не подставлять эмодзи-фолбэк. ESLint-правило `no-emoji-as-icon` ловит
  пиктографические эмодзи (не трогает типографику `× → · —` в тексте: множитель, стрелка ветра,
  разделитель). Кандидаты на дозаказ, если понадобятся как иконки: `angle` (∠) и `power` (⚡) —
  сейчас только в HUD игрового экрана (отдельный трек).
- **Компоненты `shared/ui`**: существующие (Button, Panel, Select, Dialog, ShareButton) +
  новые из инвентаря — TextInput (email/пароль/ошибка/disabled), SegmentedControl/Tabs, Toggle
  (`role="switch"`), Avatar/FactionBadge, HPBar (пороги цвета), PipRow (снаряды/ходы), Toast,
  WeaponSelector, ChatBubble. Каждый — public API + тесты.
- **Состояния**: focus-visible, loading/спиннер, disabled, skeleton, пустое, ошибка-баннер —
  реализованы и показаны **явными статичными срезами**.
- **Попапы/оверлеи**: Dialog (game-over с `data-outcome`), экран **Пауза/Настройки** — как компоненты.
- **Экраны (views)**: кодификация каталожных версий экранов по инвентарю (данные — заглушки).
- **Витрина `/design-system`**: приведена 1:1 к инвентарю; **все элементы и состояния показаны
  статично, без interaction-gated демонстраций** — убрать «кликни чтобы открыть/увидеть», фокусы
  и раскрытия по взаимодействию; каждое состояние — отдельный видимый срез рядом. Это и есть
  требование консистентности + пригодности под визрегрессию.

## Не в скоупе

- **Игровой экран** (Canvas, арена, тач-физика) — отдельный трек; арена/фон/танки — сменяемый арт.
- **Бизнес-логика экранов** (auth, лидерборд, daily, реплеи — API/данные) — здесь только верстка и
  компоненты, данные — заглушки.
- **Барьер консистентности** (poupe-lint токенов + скриншот-регрессия) — отдельный PRD
  `design-consistency-gate` (эта фаза — его мишень).
- **i18n** (next-intl) — отдельный шаг роадмапа.

## Технические ограничения

- FSD 2.1 (импорты сверху вниз, public API через `index.ts`); React 19 (без `useMemo/useCallback/memo`);
  Tailwind 4 `@theme`; отступы 4 пробела; `no-explicit-any`.
- Шрифты **self-host** из `public/fonts` (`@font-face`), НЕ `next/font/google`/CDN — гейт билдится офлайн.
- Компоненты серверные по умолчанию; `'use client'` только где нужен интерактив.
- Иконки — inline SVG на `currentColor`, тема-aware через `--accent`/text-токены; эмодзи как иконки запрещены.
- Источник дизайна — `design-inventory.dc.html`, кодифицировать **1:1**; статус фаз — на доске
  (не вести прогресс руками в доке).

## Критерии готовности

- [ ] DotGothic16 self-host, `--font-display` = DotGothic16, все заголовки/лого на нём; офлайн-билд гейта зелёный.
- [ ] `<Icon>` покрывает весь набор инвентаря; **0 эмодзи-иконок** в `src/` (ESLint-правило `no-emoji-as-icon` зелёное).
- [ ] Все компоненты из инвентаря присутствуют в `shared/ui` с public API и тестами.
- [ ] Каждое состояние каждого компонента показано на `/design-system` **статичным срезом** (нет вида, доступного только по клику/фокусу).
- [ ] Экран Пауза/Настройки и компонент Toggle реализованы.
- [ ] `/design-system` визуально **1:1 с инвентарём** — Playwright по 390/768/1280/1920, консоль чистая.
- [ ] `lint` / `lint:fsd` / `typecheck` / `test` / `build` — зелёные.
