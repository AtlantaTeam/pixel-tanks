и в самих карточках (#478, #480, #482, #484). Весь трафик шёл через локальный прокси.

## Что показал мокап

1. **Небо решает.** Бой перестал быть чёрным прямоугольником и стал похож на заставку.
2. **HUD рассчитан на тёмный фон.** Подложка панелей (`HUD_SURFACE`) и glow-текст
   проектировались поверх чёрного; на светлом небе контраст надо перепроверять заново —
   это работа для #479, а не «потом поправим».
3. Прозрачные панели на мокапе — артефакт метода (чёрные пиксели вырезаны программно),
   а не реальное поведение.

## Чего в промптах не хватило

- **Число объектов не соблюдается** («5 корпусов» → 4): просить по одному объекту на вызов.
- **Спрайт-лист режется по краям**: генерировать кадры отдельно и собирать лист самим.
- **Бесшовность не гарантирована** ни одним промптом: проверять стыковкой и, если надо,
  доводить руками.
