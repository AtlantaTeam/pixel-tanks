**Версия:** 1.0 · **Дата:** 2026-07-24 · **Статус:** черновик для команды
**Прод:** pixeltanks.ru · **Стек:** Next 16 / React 19 / Canvas / Payload CMS 3

## 0. Видение в одном абзаце

Аркадная артиллерийская дуэль в духе Scorched Earth / Worms: два танка по углам песчаной арены, ветер, разрушаемый рельеф, «один выстрел решает всё». Русскоязычная, ретро-неон-пиксель, две фракции — зелёный игрок против фиолетового бота-«Терминатора» с характером. Ядро — **точность под давлением** (угол + сила + поправка на ветер), обёрнутая в «сочность» (частицы, тряска, slow-mo, звук) и в поводы возвращаться (бой дня, реплеи-ссылки). **[ФАКТ, README + prd.md]**

## 1. Core loop

### 1.1 Цикл хода [ФАКТ, game-play.ts]

```
СВОЙ ХОД
  1. Прицел      — угол ствола (мышь / стрелки / оттяжка пальцем)
  2. Сила        — мощность выстрела (колесо / Ctrl+стрелки / длина оттяжки)
  3. (опц.) Манёвр — сместить танк в пределах бюджета ходов, сменить оружие
  4. Поправка    — учесть ВЕТЕР (постоянный боковой снос снаряда)
  5. ОГОНЬ       — снаряд летит по параболе с трейлом, звук выстрела
  6. Разрешение  — попадание/промах: урон очками, взрыв, кратер, косметика
  7. Смена хода  → ХОД БОТА (симуляция прицеливания) → назад к шагу 1
КОНЕЦ: у кого-то кончились снаряды → победитель по очкам
```

Ход **строго пошаговый**, автосмена активного танка после падения снаряда (`changeActiveTank`). Пока снаряд в полёте / кратер осыпается / летят частицы — ввод заблокирован. **[ФАКТ]**

### 1.2 Что делает петлю затягивающей [ДИЗАЙН]

- **Читаемый провал по своей вине.** Промах всегда объясним: «недокрутил силу», «забыл про ветер». Игрок видит трейл снаряда и точку недолёта — сразу понятно, как поправиться. Рождает «ещё один выстрел».
- **Ветер как загадка каждого матча.** Значение фиксировано на бой, но неизвестно точно на глаз — первый выстрел это пристрелка. **[ФАКТ: `generateWind`]**
- **Разрушаемый рельеф меняет задачу по ходу боя** — укрытие бота можно срыть. **[ФАКТ: `ground.fall`]**
- **Живой антагонист.** Бот огрызается репликами на попадания/промахи. **[ФАКТ: `emitBotReply`]**
- **Короткая сессия.** 5 снарядов на игрока → бой 2–4 минуты. **[ФАКТ: `WEAPONS_AMOUNT`, 5 на танк]**

## 2. Механики детально

### 2.1 Физика снаряда [ФАКТ, bullet.ts]

| Параметр           | Значение                                                 | Заметка                          |
| ------------------ | -------------------------------------------------------- | -------------------------------- |
| Гравитация         | `dy += 0.1` за тик                                       | постоянная, парабола             |
| Ветер              | `dx += wind` за тик, `wind ∈ [-0.01, 0.01]`              | боковое ускорение, накапливается |
| Стартовая скорость | `cos/sin(angle) × power`                                 | из дула активного танка          |
| Отскок от стен     | боковые **и верхняя** упругие (`elasticity = 1`)         | нижняя граница = снаряд исчезает |
| Радиус взрыва      | растёт до `explosionMaxRadius = 50`, затем осыпает грунт |                                  |
| Самопопадание      | только если `canHarmYourself` (у игрока всегда true)     | самострел штрафует очки          |

**Детерминизм:** физика по инжектируемому seed (`TSeededRandom`). Косметика (частицы/тряска) — на **отдельном** потоке random, чтобы FPS не сдвигал выборки бота и не ломал реплей. **[ФАКТ, критично]**

### 2.2 Разрушение террейна [ФАКТ, ground.ts]

Рельеф — массив высот `heights[x]` по seed. Взрыв → `fall(x, y, radius)`: полукруглый кратер, грунт осыпается покадрово. Статичный террейн в offscreen-слое. Танк наклоняется по локальному уклону.

### 2.3 Перемещение танка [ФАКТ, tank.ts + game.store.ts]

- Бюджет **4 хода** на матч (`moves: 4`), каждый сдвиг тратит один.
- Сдвиг по шагам с отскоком от границ. Подскок при попадании (`jumpOnHit`).
- **[ДИЗАЙН]** Манёвр — тактический ресурс; нужен индикатор «осталось ходов» в HUD.

### 2.4 Оружие

**Сейчас [ФАКТ, weapons.ts]:** один тип — «Снаряд» (радиус 50), 10 на бой, детерминированно (чётные id игроку, нечётные боту). В `tank.ts` — `TODO` про разное оружие: многооружейность заложена, не сделана.

**[ДИЗАЙН] Предлагаемый арсенал** (мапится на `TWeapon`):

| Оружие              | Эффект                            | Сложность                                      |
| ------------------- | --------------------------------- | ---------------------------------------------- |
| Фугас (есть)        | базовый, радиус 50                | —                                              |
| Мощный заряд        | радиус ~90                        | S                                              |
| Кластер             | делится на 3–5 суб-снарядов       | M                                              |
| Роющий              | насыпает грунт (вал)              | M                                              |
| Щит (действие хода) | поглощает следующее попадание     | M                                              |
| Прыгающая           | высокая elasticity, обход рельефа | S                                              |
| Наводящаяся         | коррекция к цели                  | L — **[РАЗВИЛКА]** ломает «честность» параболы |

Раздача оружия — **детерминированная** (или в реплей), иначе реплеи/бой дня разъедутся.

### 2.5 HP / урон — [РАЗВИЛКА: расхождение факта и дизайн-системы]

- **[ФАКТ, score.ts]** В коде **нет HP**. Матч — **очковая дуэль** на фиксированном боезапасе: попал в врага `+power`, самострел `−power`, побеждает больший счёт при исчерпании снарядов.
- **[ФАКТ, token-spec §6]** Дизайн-система рисует **HP-бар** (`success→warning→danger`).
- **[РАЗВИЛКА §9-A]** Выбрать модель победы: (A) очки как в коде; (B) HP + добивание (переписывает `score.ts`, драматичнее); (C) гибрид. Рекомендация: B/C для читаемости новичком, но затрагивает ядро. Решить до фазы лидерборда.

### 2.6 Сложность бота [ФАКТ, game-play.ts: botAiming/virtualFire]

- Бот **реально симулирует выстрелы** (`virtualFire`: перебор угла шаг 0.01, силы 2..18 по настоящей физике).
- Вносит ошибку прицела ∝ `(maxGameDifficulty − gameDifficulty)`; `gameDifficulty = 1..5`, старт 1.
- Не может попасть → двигает свой танк.
- **[ДИЗАЙН]** Селектор сложности есть в токенах; связать UI→`gameDifficulty`. Тиры: **Новобранец (1) / Стрелок (3) / Терминатор (5)**.

## 3. Режимы игры

| Режим                | Статус                        | Суть                                                    | Сложн.                 |
| -------------------- | ----------------------------- | ------------------------------------------------------- | ---------------------- |
| vs Бот (Быстрый бой) | **[ФАКТ] есть**               | случайный seed, дуэль до исчерпания снарядов            | —                      |
| Бой дня (daily)      | **[ФАКТ] в PRD**              | единый seed на сутки для всех → лидерборд дня           | M                      |
| Реплеи-ссылки        | **[ФАКТ] есть driver+canvas** | бой = `seed + размер + ходы`, по ссылке без регистрации | M                      |
| Испытания            | **[ДИЗАЙН]**                  | фиксированные постановки                                | M                      |
| Endless / волны      | **[ДИЗАЙН]**                  | серия ботов, счёт до смерти                             | M (зависит от §2.5)    |
| Асинхронный PvP      | **[ФАКТ] бэклог**             | ходы через реплеи                                       | L                      |
| Реалтайм PvP         | **[ФАКТ] бэклог**             | WebSocket/WebRTC                                        | XL **[РАЗВИЛКА §9-B]** |

Приоритет: Быстрый бой (готов) → Бой дня → Реплеи → Испытания.

## 4. Прогрессия и мета

- **[ФАКТ]** Очки за бой; инфраструктура лидерборда (Payload `users`+`scores`).
- **[ДИЗАЙН]** Лидерборд глобальный + отдельный «Бой дня» (честно — рельеф один). Профиль (ник, аватар-фракция, винрейт, стрик). Стрик боёв дня как крючок возврата.
- **[РАЗВИЛКА §9-C]** Разблокировки оружия vs баланс лидерборда → рекомендация: в лидерборде единый арсенал, разблокировки только косметика.
- **[ФАКТ] бэклог**: скины танков (генерация артов). **[РАЗВИЛКА §9-D]** монетизация — дефолт нет (учебный).

## 6. Feel / Juice / Аудио

- **[ФАКТ] реализовано**: частицы-пул (96), screen shake (trauma: промах 0.5 / попадание 0.85), slow-mo на попадании, трейл снаряда, подскок танка, осыпание кратера, уважение `prefers-reduced-motion`.
- **[ФАКТ] аудио — скоуп**: музыка меню/боя + fire/hit/miss + mute; хуки `getAudioEngine().playSfx(...)` на месте, нужны ассеты (`../pocket-tanks/static/audio/`). Старт только после жеста (autoplay policy).
- **[ДИЗАЙН] усилить**: анимация HUD (плавно, не скачком), печать реплики бота по буквам, финальный slow-mo на победном выстреле, экранная вспышка по фракции. Проверка скиллом `game-feel`. Деградация на слабых устройствах (FPS ≥30 моб / ≥60 desktop).

**[ДИЗАЙН] нужные арт-ассеты** (стиль: неон-пиксель, glow, консистентно с hero):

| Ассет                                      | Зачем                   |

## 9. Открытые дизайн-вопросы (решает человек)

- **A. Модель победы: HP или очки?** Код = очки; токены рисуют HP-бар. Блокирует game-over/Endless/лидерборд. Решить до лидерборда.
- **B. PvP — вкладываемся?** Реалтайм XL; асинхронный дешевле (поверх реплеев); или PvE-only?
- **C. Разблокировки оружия влияют на баланс лидерборда?** Рекомендация: единый арсенал, косметика отдельно.
- **D. Монетизация?** Дефолт — нет (учебный).
- **E. Сколько оружий в v1?** 3–4 (фугас/мощный/кластер/роющий) или весь список?
- **F. Наводящееся оружие** — включать (ломает «честность параболы»)?
- **G. Тиры сложности бота** и стартовое значение.
- **H. Бой дня: только seed или ещё биомы/фоны по дате?** (объём арт-потока)
- **I. Разнообразие арен** — один песок или биомы?
