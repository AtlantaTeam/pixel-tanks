# Токен-справочник

Значения — в `src/app/globals.css` (`@theme` + `:root`). Источник дизайн-решений — `docs/design-system-theming/token-spec.md` (Claude Design, фаза 1, #269). Этот документ — что каждый токен означает и где его применять; при расхождении с кодом ориентир — код.

> Миграция потребителей (`shared/ui`, экраны) на эти токены — отдельная фаза 4 (#272). До неё часть UI ещё сидит на старой Pico-8 палитре (`--color-surface`/`--color-panel`/`--color-muted` с прежними значениями) — см. комментарий в `globals.css`.

## Поверхности

| Токен                   | Значение  | Применение                                      |
| ----------------------- | --------- | ----------------------------------------------- |
| `--color-bg`            | `#080c08` | Фон вьюпорта / игрового шелла                   |
| `--color-panel-raised`  | `#212f24` | Вложенные блоки, hover-строки, активный сегмент |
| `--color-border`        | `#2c3f30` | Хайрлайн-границы, разделители                   |
| `--color-border-strong` | `#3f5a41` | Границы фокусируемых контролов, рамки панелей   |

`--color-surface` / `--color-panel` / `--color-muted` из token-spec.md пока не заведены под этими именами — коллизия со старыми Pico-8-токенами того же имени, разводит фаза 4 (#272).

## Бренд / статус

| Токен             | Значение  | Ink (текст поверх)              | Применение                                         |
| ----------------- | --------- | ------------------------------- | -------------------------------------------------- |
| `--color-primary` | `#ffc21f` | `--color-primary-ink` `#241900` | Главное действие: «Огонь», «Играть», подтверждение |
| `--color-accent`  | `#48ff00` | `--color-accent-ink` `#052400`  | Интерактив, фокус-ринг, выбранное, «свой» игрок    |
| `--color-enemy`   | `#c900ff` | `--color-enemy-ink` `#1e0030`   | Враг, вражеский ход/урон                           |
| `--color-danger`  | `#ff4242` | `--color-danger-ink` `#2b0000`  | Разрушительно / низкое HP / удаление               |
| `--color-warning` | `#ffa900` | `--color-warning-ink` `#2a1600` | Ветер, риск, попадание, «BOOM»-события             |
| `--color-success` | `#48ff00` | `--color-accent-ink`            | Победа, залечено, «hit» (= accent)                 |

`primary` (золото) и `accent` (неон) разведены по роли: золото = «нажми меня», неон = «здесь ты / выбор / фокус». Не смешивать.

## Тема фракции (переключение без правки компонентов)

`--accent` / `--accent-ink` / `--glow` — семантические переменные вне `@theme` (Tailwind 4 не переключает `@theme` в рантайме). Дефолт — фракция игрока; `[data-faction='enemy']` переопределяет на вражескую палитру:

```css
:root,
[data-faction='player'] {
    --accent: var(--color-accent);
    --accent-ink: var(--color-accent-ink);
    --glow: var(--glow-accent);
}
[data-faction='enemy'] {
    --accent: var(--color-enemy);
    --accent-ink: var(--color-enemy-ink);
    --glow: var(--glow-enemy);
}
```

Компоненты читают `--accent`/`--accent-ink`/`--glow`, не цвет фракции напрямую (пример — `Button variant="accent"`).

## Типографика

Две гарнитуры, обе с полным кириллическим сабсетом, self-hosted из `public/fonts/` (не `next/font/google` — офлайн-билд гейта, см. #206):

- **`--font-display` → «Pixelify Sans»** — заголовки, крупные счётчики, лого. Кириллица, переменный шрифт (один файл покрывает 400–700).
- **`--font-ui` → «JetBrains Mono»** — кнопки, метки, тело, HUD-числа (табличные цифры). Кириллица, переменный шрифт.

Не «Press Start 2P» / «Silkscreen» — у них нет кириллицы, игра русскоязычная.

### Роли и scale

| Роль                  | Токен            | Шрифт / вес | Размер / line-height            | Прочее (утилиты на месте применения) |
| --------------------- | ---------------- | ----------- | ------------------------------- | ------------------------------------ |
| Display / лого-текст  | `--text-display` | Display 700 | `clamp(48px,7vw,96px)` / `0.95` | `letter-spacing:.02em`, glow-text    |
| Заголовок экрана (H1) | `--text-h1`      | Display 700 | `40px` / `1.05`                 | uppercase                            |
| Заголовок секции (H2) | `--text-h2`      | Display 600 | `28px` / `1.1`                  | —                                    |
| HUD-цифра (крупно)    | `--text-hud-xl`  | UI 700      | `40px` / `1`                    | `tabular-nums`, glow-text            |
| HUD-цифра / метка     | `--text-hud`     | UI 700      | `20px` / `1.1`                  | `tabular-nums`, uppercase-метки      |
| Кнопка                | `--text-button`  | UI 700      | `16px` / `1`                    | `letter-spacing:.06em`, uppercase    |
| Тело / body           | `--text-body`    | UI 400      | `16px` / `1.5`                  | —                                    |
| Мелкое / caption      | `--text-caption` | UI 400      | `13px` / `1.4`                  | `--color-text-muted`                 |
| Микро / метка поля    | `--text-label`   | UI 700      | `11px` / `1.3`                  | uppercase, `letter-spacing:.12em`    |

Каждый `--text-*` — пара переменных Tailwind 4 (`--text-<role>` + `--text-<role>--line-height`) → генерирует утилиту `text-<role>` с размером и line-height разом (напр. `text-h1`). Вес шрифта, uppercase, letter-spacing, tabular-nums — отдельные utility-классы на месте применения (`font-bold`, `uppercase`, `tracking-wide`, `tabular-nums`), токены их не задают.
