# Бриф для Claude Design — экраны Pixel Tanks

Paste-ready. В Claude Design уже есть дизайн-система Pixel Tanks — этот промпт опирается на неё. Экраны заведены как issues #280–286 (milestone «Экраны игры · дизайн»).

---

**Экраны Pixel Tanks.** Используй уже созданную дизайн-систему Pixel Tanks (палитра, темы `player`/`enemy`, шрифты DotGothic16 + JetBrains Mono, компоненты Button/Panel/Select/Dialog) — все экраны строго на ней, единый источник токенов.

Спроектируй экраны (по одному за раз, начни с **P0**), каждый — **адаптивно**: mobile-first (portrait ~390px, `dvh`, safe-area, без горизонтального скролла) + осмысленное перетекание вверх на брейкпоинтах (планшет 768 / десктоп 1280 / широкий 1920) с reflow (что стекается / full-width / прячется); fluid где можно (`clamp()`), тач-цели ≥44px. Покажи **мобильный и десктоп** каждого экрана.

**P0** — 1) Мобильный игровой экран: Canvas + HUD (угол/сила/ветер/HP/счёт, чей ход = `data-faction`) + контролы под большой палец, жест «оттяни-отпусти» (рогатка), кнопка ОГОНЬ; на десктопе HUD-бар сверху. 2) Пауза/Настройки: звук, «спокойный HUD», язык, сложность (Новобранец/Стрелок/Терминатор).
**P1** — 3) Логин/Регистрация (email+пароль, ошибки). 4) Профиль (аватар-фракция, статистика, история, ссылки на реплеи).
**P2** — 5) Бой дня (вызов + результат/сравнение). 6) Реплей/Поделиться (плеер + карточка-шеринг).
**P3** — 7) Онбординг «Как играть» + состояния загрузка/404/ошибка.

Как готово — экспортируй; я кодифицирую в React из токенов, посмотрим вместе через Playwright.
