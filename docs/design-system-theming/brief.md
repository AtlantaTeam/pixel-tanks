# Бриф для Claude Design — дизайн-система Pixel Tanks (#269)

Скопировать в Claude Design, **приложив** `docs/images/pixel-tanks-hero.png` (и при желании `public/videos/main-hero.mp4`).

---

**Проект**: Pixel Tanks — ретро-пиксельная аркадная артиллерийская дуэль (вайб Scorched Earth / Worms). Стек: Next.js 16 + React 19 + **Tailwind 4** (`@theme` + CSS-переменные — единственный источник дизайн-токенов).

**Якорь — hero-арт** (приложен): жирный пиксель-арт, высокий контраст, **неоновое свечение**. Палитра арта: неоновые зелёные (трава, glow-обводка лого, атмосферные горы), фиолетово-маджента (лого TANKS + вражеский танк), золото/оранж экшена (вспышка, взрыв, трейл снаряда, «BOOM»), тёмный фон с зелёным виньет-свечением, коричневый грунт. **Две фракции**: зелёный игрок (звезда) vs фиолетовый враг (череп) — естественная ось тем.

**Задача**: вывести из арта цельную дизайн-систему и отдать как **token-spec**, готовый лечь в Tailwind 4 `@theme`.

**Дай**:

1. **Семантические токены** (имя + hex): фон / поверхность / панель, `primary`, `accent`, `danger`, `muted`, текст (+ эффекты glow/outline, если нужны). Реши целевую **сатурацию**: тянуть in-game UI к неоновому hero или держать спокойнее — на твой вкус.
2. **Типографика**: шрифт(ы) + роли и scale (заголовки / HUD-цифры / кнопки / текст). **Обязательна поддержка кириллицы** (игра русскоязычная).
3. **≥1 темизация** через CSS-переменные (напр. `player` / `enemy` акценты) — переключение без правки компонентов.
4. Покрыть экраны: **меню, HUD, лидерборд, game-over** и компоненты **Button, Panel, Select, Dialog**.

**Рамки** (жёсткие): единый источник — Tailwind 4 `@theme`; WCAG-контраст на тёмном фоне; **свобода выбора** шрифтов / палитры / эффектов / тем за тобой — hero-арт это якорь, не клетка. Текущий приглушённый Pico-8 сабсет (фон `#1a1c2c`, панель `#29366f`, primary `#ffcd75`, accent `#38b764`, danger `#b13e53`) — лишь стартовая точка, можно пересмотреть.

**Формат вывода**: список токенов (имя → значение → где применять), выбор шрифтов с кратким обоснованием, определение тем. Чтобы легло в `docs/design-system-theming/token-spec.md`.
