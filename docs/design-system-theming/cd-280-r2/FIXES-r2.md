# Правки к ревизии 2 макета «Игровой экран» (issue #280) — промпт для Claude Design

Проверено рендером `PT-Game.dc.html` ревизии 2 (390 / 768 / 1920) + замер переполнения
в браузере. Закрыто 19 из 21 пункта предыдущего ревью; ниже — остаток.

```
Ревизия 2 разобрана — 19 из 21 пункта закрыты, вердикты по дуге, ветру и кнопке ОГОНЬ
принимаю все три. Правило «телеметрия живёт в верхнем оверлее, иначе садится на танки при
любом рельефе» — то, что нужно. Осталось три вещи.

1. БЛОКЕР: ПЛАНШЕТ 768 ПЕРЕПОЛНЕН ПО ГОРИЗОНТАЛИ.
Верхняя полоса не влезает в ширину. Замер в браузере: блок телеметрии уходит до right=926px
при вьюпорте 768 — 158px за краем, при scrollWidth=768. То есть ВЕТЕР целиком и часть
СНАРЯДОВ/ХОДОВ не видны и не доскролливаются. HP-бары при этом сжаты примерно до 40px —
главная информация боя пропала с экрана.
Нужно: разложить верх планшета в два ряда (HP-бары + пилюля + mute/пауза сверху,
телеметрия отдельным рядом) либо убрать ± с планшета и ужать ячейки; HP-барам задать
min-width, чтобы они не схлопывались первыми. Проверь, что на 768 ничего не выходит
за правый край.

2. ПОДПИСЬ «ТВОИ ЧИСЛА ЗАМОРОЖЕНЫ ДО КОНЦА ХОДА СОПЕРНИКА» ИДЁТ БЕЗ ПОДЛОЖКИ.
Лежит прямо на арене — ровно тот случай, который мы уже поправили для подсказки жеста.
На светлом скине пропадёт. Ей нужна та же подложка + контур по правилу E, либо она
переезжает внутрь ячейки телеметрии.

3. CSS РАСХОДИТСЯ С СОБСТВЕННОЙ КАРТОЧКОЙ РЕШЕНИЙ.
Карточка 13–17 говорит «glow-enemy .55/.35; calm гасит в 0 0 0 transparent», а в стилях
экспорта осталось --glow-enemy: .6/.4 и [data-intensity=calm] → none. Приведи стили
в соответствие — мы кодируем по файлу, а не по описанию.

И один вопрос: пунктир «ЗОНА ЖЕСТА» с меткой — это аннотация макета или элемент прода?
Если элемент — скажи, когда он показывается (первый бой, онбординг, всегда), потому что
постоянная пунктирная рамка поверх арены будет мешать. Мелочь: в состоянии aim чип
предпросмотра перекрывает эту метку.
```
