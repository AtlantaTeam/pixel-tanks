03 — Контраст и режимы

HUD над любым скином

Правило: любой HUD-элемент = подложка rgba(8,12,8,.80–.86) + blur(4px) + рамка 2px токеном роли + внешний контур 0 0 0 1px rgba(0,0,0,.9). Контур — то, что держит HUD над светлым песком, blur — над мелким шумом рельефа. Цвета арта в контракт не входят.
