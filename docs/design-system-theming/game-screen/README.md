# Игровой экран боя — дизайн-исходники (issue #280)

Финализированный макет боевого экрана `/game` от Claude Design: Canvas-арена + оверлейный
HUD + тач-рогатка. Человеческая фаза дизайна ([#280](https://github.com/AtlantaTeam/pixel-tanks/issues/280))
закрыта на **ревизии 3**; отсюда идёт агентская кодификация.

| Файл                        | Что это                                                                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------- |
| `handoff.md`                | **Спека.** Layout по слоям, точные значения, все состояния, модель состояния, что менять в коде |
| `pt-game.dc.html`           | Сам экран, параметризованный: `variant` m/t/d/w, `state`, `outcome`, `skin`, `intensity`        |
| `game-screen-final.dc.html` | Секция-экспорт: решения A–G, кадры брейкпоинтов и состояний, таблица размеров                   |

**`handoff.md` — источник правды по виду экрана.** Разошлось с кодом — прав `handoff.md`,
кроме пунктов, где он сам ссылается на «канон кода» (пипы 14×14, HP-трек 12px, токены).

## Как открыть `.dc.html`

Файлам нужен рантайм Claude Design `support.js` — он **намеренно не в репозитории** (66 КБ
чужого рантайма, к продукту отношения не имеет). Чтобы посмотреть макет:

1. взять `support.js` из любого экспорта Claude Design и положить рядом с `.dc.html`;
2. отдать папку по HTTP (`python3 -m http.server`) — `dc-import` тянет соседние файлы
   через `fetch`, а он не работает по `file://`;
3. открыть `game-screen-final.dc.html`.

Кадры уже отрендеренного макета лежат в ветке `assets/issue-280`
(`docs/design-system-theming/cd-280-r3/`) — если нужно просто посмотреть, проще взять их.
