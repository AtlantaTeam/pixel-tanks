# Детальные брифы экранов Pixel Tanks — paste-ready промпты для Claude Design

Пошаговый набор промптов на каждый из 7 экранов. Состав вытянут строго из
`docs/game-design/gdd.md` (GDD) и `docs/design-system-theming/token-spec.md` (дизайн-система).

**Легенда пометок внутри промптов:**

- **[GDD]** — факт из Game Design Document (механика, режим, число, принятое решение).
- **[DS]** — из token-spec (токен, тема, компонент, роль типографики).
- **[+]** — дизайнерское дополнение поверх источников (моё, требует подтверждения).

---

## Инструкция по использованию

1. Открой Claude Design. В нём уже загружена **дизайн-система Pixel Tanks** (палитра, темы
   `player`/`enemy`, шрифты Pixelify Sans + JetBrains Mono, компоненты Button/Panel/Select/Dialog).
2. **Для контекста приложи два файла** к чату Claude Design:
   `docs/game-design/gdd.md` и `docs/design-system-theming/token-spec.md`.
3. Проектируй **по одному экрану за раз**, в порядке приоритетов **P0 → P1 → P2 → P3**.
   Скопируй промпт нужного экрана из соответствующей секции ниже.
4. Каждый промпт уже содержит общие правила адаптива и требование «показать все брейкпоинты (моб/планшет/десктоп/широкий)». Ничего дописывать не нужно.
5. Как готово — экспортируй zip в корень репо (рядом с token-spec), дальше идёт React-кодификация.

**Общие правила (действуют на все экраны, не повторять вручную):**

- **[CLAUDE.md]** Mobile-first: базовый макет — portrait ~390px. Резиновое перетекание вверх
  по брейкпоинтам: планшет 768 / десктоп 1280 / широкий 1920. `dvh` вместо `vh`, safe-area
  insets, без горизонтального скролла. Fluid через `clamp()` где уместно. Тач-цели ≥44px.
- **[DS]** Всё строго на токенах: поверхности спокойные (тёмные зелёно-нейтральные),
  неон/золото/маджента — только акценты, glow, HUD-цифры. Пиксельная эстетика: радиусы
  почти нулевые (`--radius-none`), рамки `--border-w`/`--border-w-thick`, пиксель-тень
  `--edge-pixel`. Всегда показывай **все четыре брейкпоинта** (моб 390 / планшет 768 / десктоп 1280 / широкий 1920) каждого экрана — **планшет первоклассный, не после-мысль** (целевое устройство), и цель — вебвью Telegram Mini App, так что резиновость обязательна.

# P0 — критические экраны

## 1. Мобильный игровой экран (Canvas + HUD + контролы)

**Назначение:** основной экран боя — Canvas-арена с HUD-телеметрией и тач-управлением
«оттяни-отпусти» под большой палец.

```
Спроектируй ИГРОВОЙ ЭКРАН боя Pixel Tanks на дизайн-системе Pixel Tanks. Mobile-first,
покажи все брейкпоинты — мобильный (~390px), планшет (768px), десктоп (1280px) и широкий (1920px), с резиновым перетеканием между ними. Приоритет P0.

НАЗНАЧЕНИЕ: экран артиллерийской дуэли — Canvas-арена + HUD-телеметрия + тач-управление.

СОСТАВ HUD (верхний бар, компонент Panel в HUD-варианте) [DS §6]:
- Счёт/HP активного и вражеского танка. Игра на HP-МОДЕЛИ [GDD §2.5 РЕШЕНО]:
  показываем ДВА HP-бара — свой (тема player, неон-зелёный) и врага (тема enemy, маджента).
  Заливка HP-бара: --color-success → --color-warning → --color-danger по мере падения [DS §6].
- Три HUD-числа моноширинными табличными цифрами (--text-hud, tabular-nums, glow-text) [DS §2]:
  УГОЛ ствола (°), СИЛА выстрела, ВЕТЕР (боковой снос, значение фиксировано на весь бой,
  wind ∈ [-0.01, 0.01], со стрелкой направления ←/→) [GDD §2.1]. Метки над числами —
  --text-label uppercase muted.
- Индикатор «ЧЕЙ ХОД»: рамка активного игрока светится через data-faction — свой ход
  data-faction=player (glow-accent зелёный), ход бота data-faction=enemy (glow-enemy маджента).
  Ход строго пошаговый, во время полёта снаряда/осыпания кратера ввод заблокирован [GDD §1.1].
- Индикатор ОСТАВШИХСЯ СНАРЯДОВ: 5 на танк, короткая сессия 2–4 мин [GDD §1.1] — ряд из 5
  пипов/иконок, израсходованные гаснут [+].
- Индикатор БЮДЖЕТА ХОДОВ: 4 хода на матч на манёвр танка, каждый сдвиг тратит один [GDD §2.3] —
  отдельный ряд пипов «осталось ходов» [+].
- СЕЛЕКТОР ОРУЖИЯ (показывать только при >1 типа) [GDD Детали полировки]: текущее оружие +
  иконка 24px, циклическая смена. Арсенал v1 = 4 [GDD §9-E]: Фугас / Мощный заряд / Кластер /
  Роющий. На мобилке — тап по слоту; на десктопе Ctrl+←/→.
- Кнопка MUTE звука (музыка боя + fire/hit/miss) [GDD §6] — иконка в углу HUD.
- Кнопка ПАУЗА → открывает экран паузы/настроек (см. экран 2) [+].

CANVAS-АРЕНА (занимает основную площадь):
- Два танка по углам песчаной арены, разрушаемый рельеф, параболический трейл снаряда [GDD §0, §2.2].
- Chat-bubble НАД ТАНКОМ БОТА [GDD Детали полировки]: реплики Терминатора, текст печатается
  по буквам (~35 мс/символ), живёт ~3 с, затухает. Портрет Терминатора (арт) в бабле.
  Бот молчит на своём промахе/самостреле. Стиль бабла — Panel enemy-темы (маджента-акцент) [+].
- Juice уже в движке [GDD §6]: частицы, screen shake, slow-mo на попадании, подскок танка,
  осыпание кратера. Финальный slow-mo на победном выстреле → плавный переход в game-over.
  Экранная вспышка/виньетка по фракции при попадании (--glow-accent свой / --glow-enemy врага).
  Всё уважает prefers-reduced-motion.

ТАЧ-КОНТРОЛЫ (мобилка, под большой палец, детально) [GDD §1.1]:
- Жест «ОТТЯНИ-ОТПУСТИ» (рогатка) прямо по Canvas: направление оттяжки = угол ствола,
  длина оттяжки = сила. Визуализируй пунктирный вектор наведения + числовой предпросмотр
  угла/силы у пальца [+].
- Крупная кнопка ОГОНЬ (Button primary, золото --color-primary, glow-primary) [DS §5] —
  в правом нижнем thumb-зоне, ≥64px, safe-area отступ снизу.
- Кнопки МАНЁВРА танка (сдвиг влево/вправо в пределах бюджета ходов) — в левой thumb-зоне,
  дизейблятся когда ходы кончились (Button disabled: --color-muted) [+].
- Слот оружия — тап-цель ≥44px рядом с зоной большого пальца [+].

СОСТОЯНИЯ:
- Свой ход (data-faction=player, зелёный glow, контролы активны).
- Ход бота (data-faction=enemy, маджента glow, контролы заблокированы, «симуляция прицела») [GDD §2.6].
- Полёт снаряда / разрешение попадания (ввод заблокирован, играет juice) [GDD §1.1].
- Реплика Терминатора активна (печать по буквам).
- Победный выстрел → финальный slow-mo → передача на game-over.

GAME-OVER (компонент Dialog поверх затемнённого поля) [DS §5, §6]:
- data-outcome=victory → акцент зелёный accent; data-outcome=defeat → акцент danger красный.
- Крупный заголовок --text-h1 (ПОБЕДА / ПОРАЖЕНИЕ).
- Статистика --text-hud табличными: остаток HP, точность попаданий, потрачено снарядов [+ на базе GDD].
- Кнопки: [Реванш] (Button primary), [Поделиться реплеем] (Button accent — ведёт на экран 6),
  [В меню] (Button ghost) [GDD §5 поток].

АДАПТИВ:
- Мобилка (390px): HUD компактный сверху (HP-бары + числа в 2 ряда), Canvas по центру,
  thumb-контролы снизу поверх safe-area, dvh на всю высоту. Рогатка = основной ввод.
- Планшет (768): HUD в один ряд, контролы разъезжаются к краям, Canvas шире.
- Десктоп (1280+): HUD-бар единой строкой сверху [DS §6], тач-контролы скрываются —
  управление мышь/колесо/стрелки/Ctrl+стрелки [GDD §1.1]. Chat-bubble бота крупнее,
  портрет Терминатора можно вынести сбоку экрана боя.
- Широкий (1920): арена в макс-ширину с виньеткой по краям, HUD не растягивается сверх меры.

ДИЗАЙН-СИСТЕМА: Panel (HUD-вариант) [DS §5], Button primary/accent/ghost/disabled, Dialog
(game-over, наследует data-outcome). Темы через data-faction (player/enemy). Опция «спокойный
HUD» data-intensity=calm глушит glow для долгих сессий [DS §3]. Типографика: --text-hud /
--text-hud-xl для чисел, --text-label для меток, --text-h1 для game-over.
```

## 2. Пауза / Настройки

**Назначение:** оверлей паузы боя с игровыми настройками, не выходя из матча.

```
Спроектируй экран ПАУЗА/НАСТРОЙКИ Pixel Tanks на дизайн-системе. Mobile-first, покажи
все брейкпоинты — мобильный (~390px), планшет (768px), десктоп (1280px) и широкий (1920px), с резиновым перетеканием между ними. Приоритет P0.

НАЗНАЧЕНИЕ: оверлей паузы боя с настройками, без выхода из матча.

СОСТАВ (компонент Dialog / Panel поверх затемнённого игрового поля) [DS §5]:
- Заголовок «ПАУЗА» --text-h1 display [DS §2].
- ЗВУК [GDD §6]: тумблер общего звука (музыка боя + SFX fire/hit/miss) + опционально
  раздельные слайдеры музыка/эффекты [+]. Учитывать: аудио стартует только после жеста
  (autoplay policy) [GDD §6].
- «СПОКОЙНЫЙ HUD»: тумблер режима data-intensity=calm — глушит весь неон-glow до нуля,
  сохраняя цвета, для долгих сессий [DS §3].
- ЯЗЫК: Select (RU / EN) [DS §5, GDD i18n].
- СЛОЖНОСТЬ БОТА: Select с тремя тирами — Новобранец (1) / Стрелок (3) / Терминатор (5),
  связан с gameDifficulty [GDD §2.6, §9-G]. Подпись под каждым тиром: описание поведения бота
  (бот реально симулирует выстрелы, ошибка прицела тем меньше, чем выше тир) [GDD §2.6, +].
- Действия внизу: [Продолжить] (Button primary), [Начать заново] (Button ghost),
  [Выйти в меню] (Button ghost) [+].

СОСТОЯНИЯ:
- Открыт поверх активного боя (фон — затемнённая арена, overlay rgba(4,8,4,.72)) [DS §5].
- Тумблеры вкл/выкл, Select открыт/закрыт (список bg --color-panel, выбранная строка
  accent + галочка) [DS §5].

АДАПТИВ:
- Мобилка: Dialog почти full-width (отступы 16px), настройки вертикальной стопкой,
  тач-цели ≥44px, dvh, safe-area.
- Планшет/десктоп: центрированное окно фиксированной ширины (~480px), --shadow-drop,
  border --border-w-thick --color-border-strong. Настройки могут идти в 2 колонки на десктопе.

ДИЗАЙН-СИСТЕМА: Dialog [DS §5], Select (язык + сложность), Button primary/ghost, тумблеры
в стиле pixel-контролов. Типографика --text-h1 / --text-label / --text-body. Нейтральная
тема player по умолчанию.
```

```

НАЗНАЧЕНИЕ: вход и регистрация по email + пароль (Payload local auth) [GDD §8 п.10].

СОСТАВ (компонент Panel с формой) [DS §5]:
- Лого/заголовок экрана --text-h1 или --text-display [DS §2].
- Переключатель ВХОД / РЕГИСТРАЦИЯ (сегмент-контрол, активный сегмент --color-panel-raised) [+].
- Форма:
  · Поле EMAIL (Select-подобный input-стиль: bg --color-surface, border --color-border-strong,
    фокус --ring-focus) [DS §5].
  · Поле ПАРОЛЬ (с toggle показа).
  · При регистрации: поле НИК (для профиля/лидерборда — ник, аватар-фракция) [GDD §4] +

- Ссылка «Забыли пароль?» --text-caption [+].
- Метки полей --text-label uppercase [DS §2].
- ВАЖНО [GDD]: НЕ добавлять Google-логин. OAuth — только Яндекс ID, и он в ФАЗЕ 12 (не сейчас).
  Для этого экрана — только email+пароль, кнопку соц-входа не рисовать [GDD стек/§8].

СОСТОЯНИЯ [DS + правило tests негативные сценарии]:

АДАПТИВ:
- Мобилка: форма full-width в Panel, поля стопкой, ≥44px, dvh, клавиатура не должна перекрывать

- Десктоп: центрированная карточка ~420px на фоне-виньетке, опц. hero-арт/иллюстрация сбоку [+].

ДИЗАЙН-СИСТЕМА: Panel, input в стиле Select-trigger (ghost-input) [DS §5], Button primary/ghost.
Тема player (нейтральный дефолт). Ошибки — --color-danger + --color-danger-ink.

## 4. Профиль

**Назначение:** личная статистика бойца, история боёв и ссылки на реплеи.

```
Спроектируй экран ПРОФИЛЬ Pixel Tanks на дизайн-системе. Mobile-first, покажи все брейкпоинты — мобильный (~390px), планшет (768px), десктоп (1280px) и широкий (1920px), с резиновым перетеканием между ними. Приоритет P1.

НАЗНАЧЕНИЕ: личная статистика игрока, история боёв, ссылки на реплеи.

СОСТАВ [GDD §4 мета]:
- ШАПКА: аватар-ФРАКЦИЯ (зелёный player / фиолетовый — тема задаёт glow и рамку через
  data-faction) [DS §3, GDD §4], НИК игрока (--text-h1 display), дата регистрации/тег [+].
- БЛОК СТАТИСТИКИ (карточки Panel, HUD-цифры --text-hud-xl табличные + glow-text) [DS §2, §6]:
  · ВИНРЕЙТ (%) [GDD §4].
  · ТОЧНОСТЬ попаданий (%) [+ на базе HP-модели: попадания/выстрелы].
  · ЛУЧШИЙ СЧЁТ / макс. остаток HP [GDD §4].
  · СТРИК боёв дня — серия подряд, крючок возврата, выделить как ключевую метрику
    (--color-primary + glow-primary, «на огне») [GDD §4].
  · Всего боёв / побед [+].
- ИСТОРИЯ БОЁВ (список/таблица, строки Panel) [GDD §4]:
  · Каждая строка: дата, режим (Быстрый бой / Бой дня), результат (победа/поражение —
    accent зелёный / danger красный), счёт/остаток HP, сложность бота.
  · ССЫЛКА НА РЕПЛЕЙ каждого боя [GDD §4, §3] — иконка/кнопка «Смотреть реплей» → экран 6.
    Реплей = seed + размер + ходы, открывается по ссылке без регистрации [GDD §3].
- Действия: [Играть] (Button primary), [Настройки], [Выход] [+].

СОСТОЯНИЯ:
- Загрузка (скелетоны карточек статистики).
- Пусто (новый игрок, боёв нет — иллюстрация + CTA «Сыграй первый бой») [+].
- Ошибка загрузки данных (баннер --color-danger + повтор).
- Заполнено.

АДАПТИВ:
- Мобилка: шапка сверху, статистика 2×N сеткой карточек, история — вертикальные карточки
  (не таблица), full-width, dvh.
- Планшет: статистика в ряд, история — компактная таблица.
- Десктоп (1280+): двухколоночно — слева шапка+статистика, справа история со скроллом.
- Широкий: max-width контейнер по центру, не растягивать таблицу бесконечно.

ДИЗАЙН-СИСТЕМА: Panel (карточки статистики + строки истории), Button primary/ghost.
Аватар-фракция через data-faction (player/enemy темы). --text-hud-xl для цифр статистики,
--text-h1 для ника, --text-caption для дат. Стрик — акцент primary/glow-primary.
```

# P2 — бой дня и реплеи

## 5. Бой дня (вызов + результат/сравнение)

**Назначение:** ежедневный вызов на едином seed с лидербордом дня.

```
Спроектируй экран БОЙ ДНЯ Pixel Tanks на дизайн-системе. Mobile-first, покажи все брейкпоинты — мобильный (~390px), планшет (768px), десктоп (1280px) и широкий (1920px), с резиновым перетеканием между ними. Приоритет P2.

НАЗНАЧЕНИЕ: ежедневный вызов — единый seed на сутки для всех игроков → отдельный лидерборд дня.

СОСТАВ [GDD §3 daily, §4 мета]:
СОСТОЯНИЕ «ВЫЗОВ» (до боя):
- Заголовок «БОЙ ДНЯ» + дата --text-h1 display [DS §2].
- Уникальный ФОН/БИОМ дня (день/закат/ночь/буря — арт-поток) как превью арены [GDD §9-H/I].
- Условия боя: сложность, ветер-подсказка (значение фиксировано на бой) [GDD §2.1],
  единый рельеф для всех — «честное сравнение» [GDD §4].
- Твой СТРИК боёв дня (серия подряд, --color-primary + glow-primary) [GDD §4].
- Индикатор «сыграно/не сыграно сегодня» [+].
- Кнопка [Принять вызов] / [В бой] (Button primary) → игровой экран с daily seed.

НАЗНАЧЕНИЕ: обучение базовой петле хода новичка + системные экраны-заглушки.

**Ключевые сквозные факты, которые дизайн не должен потерять:**

- **HP-модель решена** [GDD §2.5] — HP-бары каноничны, не «очки». Победа = добить до 0 HP;
  при исчерпании снарядов — больший остаток HP.
- **Темизация через атрибуты** [DS §3]: `data-faction` (player/enemy), `data-outcome`
  (victory/defeat), `data-intensity="calm"`. Никаких условных классов в разметке.
- **Разведение ролей цвета** [DS §1]: золото `--color-primary` = «нажми/действие»,
  неон `--color-accent` = «здесь ты / выбор / фокус». Не смешивать.
- **OAuth только Яндекс ID и позже** [GDD] — на экране логина никакого Google.
- **Реплей без регистрации** [GDD §3] — бой = seed+размер+ходы, детерминизм.
